# Entreno — asistente de entrenamiento

App Android personal para entrenar con progresión automática de cargas, descansos cronometrados que suenan con el móvil bloqueado, recordatorio diario offline, perfil con cálculo de calorías/macros y plan de dieta. Todo se guarda en el móvil (SQLite) con copia de seguridad opcional en GitHub.

**Estado:** planificación. Nada implementado todavía.

- Plan completo, decisiones y hoja de ruta: [PLAN.md](PLAN.md)
- Instrucciones para agentes: [AGENTS.md](AGENTS.md)
- Datos iniciales (rutinas, alimentos, dieta) extraídos del Excel original: [data/seed/seed.json](data/seed/seed.json)

Stack: Expo (React Native) + TypeScript · expo-router · expo-sqlite + Drizzle · expo-notifications.
